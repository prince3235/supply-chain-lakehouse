# Supply Chain Lakehouse — Notebooks & Interactive Walkthroughs

This directory contains end-to-end interactive workflows demonstrating the data science and machine learning lifecycle across the lakehouse.

## Notebook Catalog

| Script / Notebook | Purpose | Key Modules Used |
|---|---|---|
| `01_demand_forecasting_walkthrough.py` | Complete end-to-end walkthrough from Gold demand to ML models, inference, and replenishment purchase orders. | `src.features`, `src.training`, `src.inference`, `src.monitoring` |

## How to Run

Execute standalone via:
```bash
python notebooks/01_demand_forecasting_walkthrough.py
```
